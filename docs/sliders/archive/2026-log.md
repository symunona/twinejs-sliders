- 2026-09-19 — Bubbles get a HAND MODE: `sizing: manual`, `bubble: {tail: […]}`, eight resize
  handles and a draggable anchor cross. Commits `47f0bf83` + `a222d3ac`, deployed to twine-ig.
  THREE SIZINGS, and the third is the one that was missing: `auto` fits the BOX to the words,
  `absolute` fits the TYPE to the box, `manual` is `absolute`'s box with `auto`'s type (clips,
  no fit search). One branch in `sizeBubble` (`fixed = absolute || manual`), and only
  `absolute` calls `fitText`; a switch away from absolute must clear `body.style.fontSize` or
  the old fitted size sticks. `.sliders-box` had NO height at all — `positionBox` only ever
  wrote `w` — so a narration bar took an `h:` handle drag and did nothing; it now honours a
  fixed sizing too.
  `tail: [x, y]` is stage fractions, NOT an offset from the speaker: the point of naming it is
  usually something that is not the speaker (a door, someone off frame), and an offset would
  walk away with the sprite. It substitutes for `measure(who, 'bubble')` wholesale, so an
  unpinned bubble also hangs off it (`placeBubble` takes the same `anchor`). Unclamped, unlike
  `pinnedRect` — a tail may reach past the frame. `anchor: scene` ignores it, growing no tail
  at all.
  THE EDITOR NEVER RE-MERGES THE STYLE. Four layers produce what is on screen (story vars <
  scene < character < beat) and only the renderer has merged all four, so `bubble-editor.tsx`
  reads `data-sizing` and `data-anchor-mode` back OFF the bubble element, and the dialogue
  layer publishes the tail point as `data-anchor-x`/`data-anchor-y` (`setAnchorData`). Those
  are from the BUBBLE'S OWN TOP LEFT, not mount px — the editor measures in frame pixels and
  would otherwise need a way into the renderer's coordinate space for one number. Rounded,
  because the editor's rAF measure loop diffs a JSON key 60 times a second.
  Every handle grows about the bubble's CENTRE, so a resize never rewrites `at:`. Vertical
  handles PROMOTE an auto bubble to `manual` and carry the width it already had across

  default panel on the first pixel. Promotion is the only discoverable way into `manual`; the
  Sizing dropdown in the beat row offers it too, for free, since it maps `BUBBLE_SIZINGS`.
  `BubbleGeometry` already carried `h`/`sizing`/`anchor`, so the write path needed only `tail`
  plus `formatBubbleValue` treating it like `at` (a `[x, y]` pair, never the bare-number form).
